# Crew Manager — Updates

**Crew Manager** reads your 2K HQ crew's roster (inside
BlueStacks), tracks every member's Weekly and Total Crew XP,
and posts stats reports to your Discord — automatically,
every morning.

This page is the official update home for Crew Manager.

## How updates work

- Crew Manager checks this page **once a day** for a newer
  version (it reads the small `version.json` file here).
- When an update exists, the app shows a banner:
  **"Crew Manager X.Y.Z is available"** with a
  **Get the update** button that brings you here.
- Nothing ever downloads or installs itself. You download
  the new installer from **Releases** (top of this page)
  and run it — it installs over the old version, and your
  roster, history, and settings are kept (they live
  outside the install folder).

## The honest risk — read this first

> 2K's rules ban "bots in any form or fashion," and Crew
> Manager does automate menu clicks in the 2K HQ app to
> read your roster (it never plays the game). 2K has
> permanently banned accounts over automation. Using Crew
> Manager means using your own 2K account at your own
> risk — read the full disclosure in the installer before
> you install.
